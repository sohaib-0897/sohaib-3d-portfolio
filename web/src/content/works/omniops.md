Multimodal ingestion for PDF, OCR, and audio, backed by hybrid retrieval combining PostgreSQL full-text search and pgvector dense search through Reciprocal Rank Fusion.

Database-leased workers handle background processing; authenticated SSE streams progress. Workspace isolation and sandboxed, model-invoked tools support investigations with DuckDB. Deployed with Docker and Caddy.
