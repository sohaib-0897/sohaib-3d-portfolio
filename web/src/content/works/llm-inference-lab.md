Explores KV cache, grouped-query attention (GQA), RoPE, speculative decoding, INT8 quantization, and ONNX export. Ollama benchmarks measure GPU offloading, time to first token (TTFT), token throughput, VRAM usage, and context scaling.

## Benchmark context

Measured on an **NVIDIA RTX 4050 Laptop GPU with approximately 6 GB VRAM**. A **Qwen 0.5B test reached approximately 227 tokens/sec**; this is a model-specific test result, not universal model performance.
