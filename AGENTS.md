# AGENTS.md

Project conventions and architecture notes for AI coding assistants live in **[CLAUDE.md](CLAUDE.md)** — read it first.

The repo is organized into: the front-end app in [`web/`](web), the 3D Blender assets in [`blender/`](blender), project documentation in [`docs/`](docs), and testing/automation scripts in [`scripts/`](scripts). **All front-end code paths are relative to `web/`**, and npm commands run inside `web/`.

Quick start:

```bash
cd web
npm install
npm run dev   # http://localhost:5173
```
